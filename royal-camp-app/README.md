# 로열캠프 알리미

React + TypeScript + Tailwind + Vite로 만든 로열캠프 알리미 앱입니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 나오는 주소(보통 http://localhost:5173)를 브라우저에서 열면 됩니다.

## 데모 데이터

이 프로젝트는 실제 Firebase 없이도 바로 체험할 수 있도록, 브라우저의 localStorage를
간이 데이터베이스처럼 사용합니다. 처음 실행하면 아래 데모 데이터가 자동으로 채워집니다.

- 회원가입은 제한 없이 누구나 아이디를 직접 정해서 가입할 수 있습니다 (이미 사용 중인 아이디만 막습니다).
- 관리자 로그인: `/login` 화면의 아이디/비밀번호 칸에 아이디 `royalcamp` / 비밀번호 `camp2026!`를 입력하면 관리자 대시보드로 이동합니다 (`.env` 파일에서 변경 가능). 별도의 관리자 로그인 화면은 없습니다.

## 화면 구성

- `/login`, `/signup` — 학생/관리자 로그인 · 회원가입 (아이디, 비밀번호, 이름, 휴대폰번호). 로그인 화면에 관리자 아이디/비밀번호를 입력하면 관리자 대시보드로 이동합니다.
- `/home` — 다크블루 헤더 + 내 정보 / 학교정보 / 공지사항 / 가이드북 2x2 카드
- `/guidebook` — 일정표(디데이 + 관리자 공지 배너) / 규칙 / 캠프 개요 / 비밀 유지 계약서
- `/admin` — 관리자 대시보드 (공지사항, 디데이, 일정표, 학생 명단, 학교정보, 가이드북 관리)

## 나중에 실제 서비스로 확장하려면

지금은 `src/lib/storage.ts`가 localStorage로 데이터를 다루고 있어요. 실제 서비스로
확장할 때는 이 파일의 함수들(예: `getNotices`, `addNotice`, `getSchedule` 등)의
내부 구현만 Firebase Firestore 호출로 바꾸면, 나머지 화면 코드는 거의 그대로
쓸 수 있도록 구조를 분리해뒀습니다.
